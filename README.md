# SmartReplacer VS Code extension

`smartreplacer-vscode-0.1.0.vsix` — install on Windows:

1. Download the `.vsix` from this repo (use the **Download raw file** button on the file page, or `git clone` and grab it).
2. In VS Code: `Ctrl+Shift+X` → `...` menu (top-right of Extensions panel) → **Install from VSIX...** → pick the file.

Or from the command line:

```
code --install-extension smartreplacer-vscode-0.1.0.vsix
```

Reload window when prompted. Look for the SmartReplacer icon in the activity bar.
